Tipo Entero — Número sin decimales

Almacena valores numéricos enteros (positivos o negativos) sin parte fraccionaria

int temperatura = 25;

Tamaño fijo: ocupa exactamente 4 bytes (32 bits) en memoria. Rango: de −2,147,483,648 a +2,147,483,647. La declaración del tipo int es obligatoria antes del nombre de la variable.
⚠ Tipado Estático — No puede cambiar

char

Tipo Carácter — Un símbolo individual

Representa un único carácter de texto basado en la tabla ASCII

C++ / Arduino
char letra = 'A';   // comillas simples
char comando = 'E'; // carácter de control
Serial.write(letra); // envía byte
1 byte exacto. En C++ char guarda un único carácter con comillas simples. Internamente es un número entero de 8 bits que corresponde al código ASCII. 'A' = 65, 'E' = 69. Se utiliza ampliamente para enviar comandos por el puerto serial.
⚠ Solo 1 carácter — comillas simples
Python 3
letra = "A"     # str de 1 char
comando = "E"   # sin tipo char
arduino.write(comando.encode()) # → bytes
Python no tiene tipo char. Un carácter individual es simplemente un string (str) de longitud 1. Se usan comillas simples o dobles indistintamente. Para enviar caracteres como bytes por serial se debe convertir con .encode('utf-8').
✓ str — maneja texto de cualquier longitud
float

Tipo Flotante — Número con decimales

Representa valores reales con parte fraccionaria según estándar IEEE 754

C++ / Arduino
float distancia = 12.75;
float voltaje = 4.95;
float promedio = (distancia + voltaje) / 2.0;
4 bytes / 32 bits (precisión simple IEEE 754). Aproximadamente 6-7 dígitos decimales de precisión. En Arduino se declara explícitamente y es crítico para el cálculo de distancias con sensores ultrasónicos.
⚠ Precisión limitada: ~7 dígitos
Python 3
distancia = 12.75
voltaje = 4.95
promedio = (distancia + voltaje) / 2
print(type(distancia)) # <class 'float'>
8 bytes / 64 bits (doble precisión). Python usa internamente el tipo double de C, lo que da ~15-17 dígitos decimales. No es necesario declarar el tipo: basta con escribir un número con punto decimal.
✓ Doble precisión: ~15 dígitos
{ }

Llaves — Delimitadores de bloques de código

Definen el inicio y fin de un bloque lógico (función, condicional, bucle)

C++ / Arduino
void loop() {
  if (sensor == 1) {
    digitalWrite(13, HIGH);
  }
}
En C++, las llaves { } son obligatorias para delimitar cualquier bloque de código. La apertura { marca el inicio y el cierre } marca el final. Sin ellas, solo la primera instrucción siguiente pertenece al bloque.
⚠ Obligatorio — el compilador lo exige
Python 3
def loop():
    if sensor == 1:
        print("LED encendido")
Python no usa llaves. El bloque de código se define mediante la indentación (sangría): 4 espacios por nivel. Un bloque mal indentado genera un error IndentationError. El : al final de la cabecera marca el inicio del bloque.
✓ Indentación — más legible, más limpio
;

Punto y coma — Terminador de instrucción

Indica al compilador/intérprete que una sentencia ha concluido

C++ / Arduino
int x = 10;           // ← ; obligatorio
digitalWrite(13, HIGH); // ← ; obligatorio
delay(1000);           // ← ; obligatorio
// Olvidar el ; = ERROR de compilación
En C++, el punto y coma ; es obligatorio al final de cada instrucción. Sin él, el compilador lanza un error. Esto permite escribir varias instrucciones en una misma línea (aunque no es buena práctica). Es uno de los errores más comunes al aprender C++.
⚠ Obligatorio — error de compilación si falta
Python 3
x = 10             # sin ;
print("encendido")  # sin ;
# El salto de línea es el terminador
# Puedes usar ; para múltiples en una línea (poco común):
a = 1; b = 2; c = 3
Python usa el salto de línea como terminador natural. El punto y coma es técnicamente válido pero no se usa en código idiomático Python. Esto hace que el código sea más limpio y legible. Para instrucciones largas se puede continuar en la siguiente línea usando \.
✓ No requerido — el enter es suficiente
*

Asterisco — Puntero, multiplicación y desempaque

Un símbolo con múltiples roles críticos en cada lenguaje

C++ / Arduino
// Multiplicación:
float resultado = 4.5 * 2.0;

// Declaración de puntero:
int *puntero;

// Desreferencia (accede al valor):
int valor = *puntero;
En C++, * tiene dos roles de puntero: al declarar una variable (int *p) crea un puntero que guarda una dirección de memoria; al usarlo sobre un puntero existente (*p) desreferencia esa dirección y accede al valor que contiene. Concepto fundamental para entender la memoria RAM.
★ Multiplicar + Punteros + Desreferenciar
Python 3
# Multiplicación:
resultado = 4.5 * 2.0

# Potencia (doble asterisco):
cuadrado = 3 ** 2  # → 9

# Desempaque de listas:
nums = [1, 2, 3]
a, *resto = nums  # a=1, resto=[2,3]
Python no tiene punteros: la gestión de memoria es automática. El operador * multiplica, mientras que ** eleva a una potencia. El asterisco también se usa para desempacar iterables en funciones o asignaciones múltiples. Mucho más seguro y sencillo.
✓ Sin punteros — memoria gestionada auto.
&

Ampersand — Referencia y operación bit a bit

Dirección de memoria en C++, operador AND binario en Python

C++ / Arduino
// Obtener dirección de memoria:
int x = 42;
int *ptr = &x;  // ptr = 0x7ffe... (dirección)

// Referencia (alias de variable):
int &ref = x;  // ref ES x (mismo espacio)

// AND a nivel de bits:
int mask = 0b1010 & 0b1100; // → 0b1000
En C++, & tiene tres usos. Como operador de dirección: retorna la dirección física en RAM de una variable. Como declarador de referencia: crea un alias (otro nombre) para la misma variable. Como operador AND bit a bit: compara los bits de dos enteros.
★ Dirección + Referencia + AND binario
Python 3
# AND a nivel de bits:
mask = 0b1010 & 0b1100  # → 0b1000 = 8

# Python no tiene operador de dirección
# pero puedes ver el id (dirección interna):
x = 42
print(id(x))  # → 9789120 (dirección interna)

# También: AND lógico (palabras)
if a and b:  # Python usa "and" no &&
    print("ambos verdaderos")
En Python, & opera exclusivamente como AND a nivel de bits (útil en programación de registros de hardware). Python no expone las direcciones de memoria directamente aunque id() devuelve un identificador interno. El AND lógico se escribe con la palabra and.
✓ Solo AND binario — sin acceso a RAM

Inmutabilidad de Constantes

Una constante es un valor que no debe cambiar durante la ejecución del programa. Python no posee la palabra clave const (como C++), por lo que se usa la convención PEP 8: identificadores completamente en MAYÚSCULAS. Es un acuerdo entre programadores, no una restricción del intérprete.

Día 4: Estructuras Cíclicas e Iteraciones

Control repetitivo y optimización de rutinas mediante bucles condicionados e iteradores.

Mecánica de Bucles While y For Algoritmia

Bucle WHILE: Itera indefinidamente mientras una condición lógica sea verdadera. Requiere una variable de control que mute en cada iteración para prevenir bucles infinitos que bloqueen el CPU.

Ciclo While — Diagrama de Flujo
Evalúa condición
True ➔
Ejecuta bloque
➔ Incrementa ➔ Volver
↓ False → Sale del bucle
Python — while
contador = 0
while contador < 5:
    print(f"Ciclo de procesamiento #{contador}")
    contador += 1  # ← CRÍTICO: sin esto → bucle infinito

# While True: bucle de monitoreo continuo (como loop() en Arduino)
while True:
    lectura = leer_sensor()
    if lectura > 100:
        break  # Salida controlada

Bucle FOR: Itera sobre una secuencia de elementos o un rango definido de números. Más seguro que el while porque el número de iteraciones está predefinido.

Python — for con range()
# Iterar un número fijo de veces:
for i in range(10):
    print(f"Muestra #{i}: {leer_sensor()}")

# Iterar sobre una lista de pines:
pines_led = [10, 11, 12, 13]
for pin in pines_led:
    print(f"Activando pin {pin}")

# range(inicio, fin, paso):
for frecuencia in range(200, 1000, 50):
    print(f"Frecuencia: {frecuencia} Hz")

Las instrucciones de control alteran el flujo normal de un bucle sin romper la estructura completa del programa:

breakSale completamente del bucle
continueSalta a la siguiente iteración
passNo hace nada (marcador de posición)
Python — control de flujo avanzado
for i in range(100):
    lectura = leer_sensor(i)

    if lectura < 0:
        continue   # Ignora lecturas negativas (inválidas)

    if lectura > 999:
        break      # Desbordamiento: detiene el ciclo completo

    procesar(lectura)
Práctica: Desarrollar una cuenta regresiva de 10 a 0 usando while, que imprima "¡Lanzamiento!" al finalizar, y luego repetirla usando for con range() en sentido inverso.

Día 5: Arquitectura de Microcontroladores y Salidas Digitales

Análisis de hardware, flujo eléctrico y modulación de estados lógicos en registros GPIO.

Componentes Críticos del Circuito Teoría de Circuitos

💡 LED ⚡ Resistencia 🔌 Protoboard 🎛️ Arduino
  • LED (Diodo Emisor de Luz): Semiconductor que emite fotones al polarizarse directamente. Terminal positivo (Ánodo) = pata más larga. Terminal negativo (Cátodo) = pata más corta + chaflán plano. Opera típicamente con 2-3V y 20mA.
  • Resistencia Limitadora (220Ω): Por la Ley de Ohm: R = (Vsrc − Vled) / Iled = (5V − 2V) / 0.02A = 150Ω. Se usa 220Ω por seguridad. Sin ella, el LED se destruye en milisegundos.
  • Protoboard: Filas A-E y F-J conectadas verticalmente en columnas centrales. Los buses laterales (+/-) conectados horizontalmente. Permite prototipar sin soldadura.
Circuito Blink — Flujo de Corriente
[Pin 13 · HIGH] ➔ Saca 5V exactos del registro GPIO
[Resistencia 220Ω] ➔ Limita la corriente a ~14mA seguros
[Ánodo LED (+)] ➔ Recibe corriente regulada
[Cátodo LED (-)] ➔ Devuelve corriente residual
[Pin GND] ➔ Masa de referencia · cierra el lazo eléctrico

Firmware Base en C++ (Arduino) Código Base

El compilador de Arduino transforma el C++ en instrucciones de máquina AVR. Dos funciones son obligatorias:

C++ / Arduino IDE
// setup(): se ejecuta UNA VEZ al energizar o presionar Reset
void setup() {
  pinMode(13, OUTPUT); // Configura GPIO 13 como SALIDA de corriente
}

// loop(): bucle infinito a 16 MHz (≈ 16,000,000 veces por segundo)
void loop() {
  digitalWrite(13, HIGH); // Registro GPIO → 5V (encendido)
  delay(1000);             // Pausa 1000ms bloqueando el CPU
  digitalWrite(13, LOW);  // Registro GPIO → 0V (apagado)
  delay(1000);
}
Práctica: Modificar los delays para crear un patrón asimétrico: 200ms encendido / 1800ms apagado. Luego calcular cuántas veces parpadeará por minuto.

Día 6: Automatización de Secuencias Multicanal

Gestión coordinada de múltiples buses GPIO e interconexión de arreglos lógicos discretos.

Sincronización Secuencial Cruzada Sistemas de Control

Al controlar múltiples actuadores simultáneamente (semáforo de 3 canales), se implementan matrices de temporización que deben garantizar exclusión mutua: nunca verde y rojo activos al mismo tiempo, ya que eso representaría una falla crítica del sistema.

Secuencia de Temporización del Semáforo
[Pin 12 · Rojo]HIGH por 3000ms → LOW · Fase de STOP
[Pin 10 · Verde]HIGH por 3000ms → LOW · Fase de PASO
[Pin 11 · Amarillo]HIGH por 1000ms → LOW · Fase de PRECAUCIÓN
[Ciclo total]7000ms por ciclo completo (≈ 8.5 ciclos/min)
C++ / Arduino — Semáforo 3 canales
void setup() {
  pinMode(12, OUTPUT); // Rojo
  pinMode(11, OUTPUT); // Amarillo
  pinMode(10, OUTPUT); // Verde
}

void loop() {
  digitalWrite(12, HIGH); delay(3000); digitalWrite(12, LOW); // 🔴 Rojo
  digitalWrite(10, HIGH); delay(3000); digitalWrite(10, LOW); // 🟢 Verde
  digitalWrite(11, HIGH); delay(1000); digitalWrite(11, LOW); // 🟡 Amarillo
}
Práctica: Añadir un cuarto LED (azul, pin 9) que represente una fase de "Peatones cruzando" entre el rojo y el verde, con duración de 2000ms.

Día 7: Adquisición de Señales Digitales (Entradas)

Monitoreo de eventos externos, acoplamiento de impedancias y mitigación de ruido electromagnético.

Estados de Flotación y Resistencias de Acoplamiento Instrumentación

Cuando un pin se configura como entrada (INPUT), adquiere alta impedancia interna (~∞Ω). Sin una referencia de voltaje fija, el pin actúa como antena captando ruido electromagnético ambiental, generando transiciones aleatorias entre 0 y 1 conocidas como estado flotante.

Pull-Down externo: Una resistencia de 10kΩ conectada entre el pin y GND fuerza el nivel bajo (0V) cuando el pulsador está abierto. Al presionar el botón, el pin se conecta directamente a VCC (5V) leyendo HIGH.

Pull-Down — Comportamiento
Pulsador ABIERTO
R a GND ➔
LOW estable (0V)
Presionar ➔
HIGH (5V)
C++ — Pull-Down externo
void setup() {
  pinMode(2, INPUT);    // Requiere resistencia 10kΩ a GND en protoboard
  pinMode(13, OUTPUT);
}
void loop() {
  int estado = digitalRead(2);
  digitalWrite(13, estado); // LED sigue al botón
}

Pull-Up interno: Arduino incluye resistencias de 20kΩ internamente que se activan por software con INPUT_PULLUP. Conecta el pin a VCC internamente: pin libre = HIGH, botón presionado = LOW (lógica invertida).

C++ — INPUT_PULLUP interno
void setup() {
  pinMode(2, INPUT_PULLUP); // Resistencia interna de 20kΩ → VCC
  pinMode(13, OUTPUT);
}
void loop() {
  int estado = digitalRead(2);
  // ¡Lógica invertida! LOW = presionado, HIGH = libre
  if (estado == LOW) {
    digitalWrite(13, HIGH); // LED encendido
  } else {
    digitalWrite(13, LOW);
  }
}
Práctica: Implementar un contador de pulsaciones usando INPUT_PULLUP. Cada vez que se presione el botón, incrementar un contador y enviarlo por Serial Monitor.

int notas[] = {261, 294, 330, 349, 392, 440, 494}; // Do Re Mi Fa Sol La Si
int duracion = 400;

void setup() {}

void loop() {
  for (int i = 0; i < 7; i++) {
    tone(9, notas[i], duracion); // pin, frecuencia, duración_ms

  }

Día 9: Telemetría por Ultrasonido (HC-SR04)

Cálculo del tiempo de vuelo de ondas acústicas para determinar distancias absolutas en tiempo real.

Principio de Eco-Localización Teoría de Ondas

El sensor HC-SR04 usa el mismo principio que los murciélagos: emite un pulso ultrasónico (40kHz, inaudible) y mide el tiempo que tarda el eco en regresar. Con la velocidad del sonido conocida, calcula la distancia exacta.

40kHz
Frecuencia del pulso
343 m/s
Velocidad del sonido
÷ 58.2
Factor de conversión (μs→cm)
Haz clic para ver la derivación matemática de la constante 58.2
Velocidad343 m/s = 0.0343 cm/μs
Ida + vueltaEl tiempo medido incluye trayectoria doble
FórmulaDistancia = (tiempo_μs × 0.0343) / 2
EquivalenteDistancia = tiempo_μs / 58.2
Por qué 58.22 / 0.0343 ≈ 58.3
Secuencia de Telemetría Acústica
[Trigger: 10μs]➔ Microcontrolador activa el transductor
[Transmisor T]➔ Emite ráfaga de 8 pulsos a 40 kHz
[Echo → HIGH]➔ Pin empieza a contar microsegundos
[Rebote]➔ Onda golpea el objeto y regresa
[Echo → LOW]➔ Para el conteo; pulseIn() retorna el tiempo
[Cálculo]➔ Distancia (cm) = tiempo_μs / 58.2

Firmware de Medición Métrica Código de Control

C++ / Arduino — HC-SR04
const int pinTrigger = 9;
const int pinEcho    = 8;
long  duracion;
float distancia;

void setup() {
  pinMode(pinTrigger, OUTPUT);
  pinMode(pinEcho,    INPUT);
  Serial.begin(9600);
}

void loop() {
  // Generar pulso de disparo de 10μs
  digitalWrite(pinTrigger, LOW);  delayMicroseconds(2);
  digitalWrite(pinTrigger, HIGH); delayMicroseconds(10);
  digitalWrite(pinTrigger, LOW);

  // Capturar tiempo de respuesta del eco
  duracion  = pulseIn(pinEcho, HIGH);
  distancia = duracion * 0.0343 / 2.0;

  Serial.print("Distancia: ");
  Serial.print(distancia, 2);  // 2 decimales
  Serial.println(" cm");
  delay(100);
}

import serial

void setup() {
  Serial.begin(9600);
  pinMode(13, OUTPUT);
}

void loop() {
  if (Serial.available() > 0) {
    char cmd = Serial.read(); // Lee 1 byte

    switch(cmd) {
      case 'E':
        digitalWrite(13, HIGH);
        Serial.println("LED encendido");
        break;
      case 'A':
        digitalWrite(13, LOW);
        Serial.println("LED apagado");
        break;
    }
  }

Python — Sistema de Control Integrado
import serial, time, datetime

arduino = serial.Serial('COM3', 9600, timeout=1)
time.sleep(2)

UMBRAL_ALARMA = 20.0  # cm

print("🚀 Sistema de automatización activo")

while True:
    if arduino.in_waiting > 0:
        trama = arduino.readline().decode('utf-8').strip()

        try:
            distancia = float(trama.replace("Distancia: ", "").replace(" cm", ""))
            ts = datetime.datetime.now().strftime("%H:%M:%S")
            print(f"[{ts}] 📡 {distancia:.2f} cm")

            if distancia < UMBRAL_ALARMA:
                arduino.write(b'A')  # ¡ALERTA!
                print(f"  ⚠️  OBJETO A {distancia:.1f}cm — Alarma activada")
            else:
                arduino.write(b'N')  # Normal
        except ValueError:
            pass  # Ignora tramas malformadas
